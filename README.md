# Visualizador IFC no GitHub Pages

Este repositório permite visualizar modelos **IFC** diretamente no navegador usando [IFC.js](https://ifcjs.github.io/info/).

## 🚀 Como usar

1. Exporte seu modelo do Revit ou BonsaiBIM em formato **IFC**.
2. Substitua o arquivo `modelo.ifc` dentro da pasta `docs/`.
3. Faça commit e push no repositório.
4. Ative o **GitHub Pages** nas configurações:
   - Vá em *Settings > Pages*.
   - Selecione branch: `main` e pasta `/docs`.
5. Acesse: `https://SEU-USUARIO.github.io/NOME-DO-REPO/`

Pronto, seu modelo 3D estará disponível online!
